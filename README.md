# Store Annual Report 2022

## 📊 Project Overview

An interactive Excel dashboard created to analyze store sales and order data for 2022.

The dashboard provides insights into sales performance, customer demographics, order status, sales channels, and state-wise performance.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Dashboard Design
- Data Visualization

## 📌 Dashboard Analysis

The dashboard covers:

- Monthly Sales & Orders
- Sales by Gender
- Order Status
- Top 5 States by Sales
- Age Group & Gender Analysis
- Sales Channel Analysis
- Category-wise Performance

## 🎯 Objective

To analyze store sales and order data and present meaningful insights through an interactive and easy-to-understand Excel dashboard.
